# chess

Консольные шахматы на Java для двух игроков за одним терминалом. Доска печатается текстом, ходы вводятся строкой вида `E2-E4`.

## Запуск

Нужна Java 11 или новее, сторонних библиотек нет.

```sh
javac -d out $(find src -name '*.java')
java -cp out Chess
```

Партия заканчивается матом или патом. Выйти раньше можно через Ctrl+D (конец ввода).

## Как ходить

Ход записывается как `откуда-куда`: `E2-E4`, `G1-F3`. Регистр не важен, `e2-e4` тоже подходит.

- **Рокировка** — ход королём на две клетки: `E1-G1` (короткая), `E1-C1` (длинная).
- **Взятие на проходе** — обычный ход пешкой по диагонали на клетку, через которую только что перепрыгнула пешка соперника.
- **Превращение пешки** — после хода на последнюю горизонталь добавьте букву фигуры: `A7-A8Q` (ферзь), `A7-A8R` (ладья), `A7-A8B` (слон), `A7-A8K` (конь). Без буквы пешка становится ферзём.

Если ход невозможен, программа печатает причину (`WrongMoveExeption[ Obstacle on road! ]`) и ждёт новый ход того же игрока.

## Доска

```
   |-A--|-B--|-C--|-D--|-E--|-F--|-G--|-H--|
-----------------------------------------------
-1-| WR |*WK*| WB |*WQ*| Wk |*WB*| WK |*WR*|-1-
-----------------------------------------------
-2-|*WP*| WP |*WP*| WP |*WP*| WP |*WP*| WP |-2-
...
-8-|*BR*| BK |*BB*| BQ |*Bk*| BB |*BK*| BR |-8-
```

Первая горизонталь печатается сверху, белые стоят там же. Клетки со звёздочками — белые поля доски.

Фигура обозначается двумя буквами: цвет (`W` — белые, `B` — чёрные) и сама фигура:

| Буква | Фигура |
|-------|--------|
| `P`   | пешка  |
| `R`   | ладья  |
| `K`   | конь   |
| `B`   | слон   |
| `Q`   | ферзь  |
| `k`   | король (строчная) |

## Правила

Поддерживаются все ходы фигур, рокировка (король и ладья не ходили, между ними пусто, король не под шахом и не проходит через битое поле), взятие на проходе, превращение пешки, шах, мат и пат. Ход, после которого свой король остаётся под шахом, не принимается.

Чего нет: ничьей по правилу 50 ходов, по троекратному повторению позиции и при недостатке материала. Такую партию можно только прервать.

## Устройство

- `src/Chess.java` — точка входа: печать доски, чтение хода, конец партии.
- `src/backs/` — модель и правила:
  - `Board` — доска 8×8 из `Tile` и списки клеток с белыми и чёрными фигурами (`TileSet`);
  - `GameProcess` — проверка и выполнение хода, шах, мат, пат, рокировка, взятие на проходе, превращение;
  - `Piece` и `pieces/` — фигуры; каждая знает, как она ходит (`moveIsObtainable`) и каким шагом идёт по линии (`getMove`).
- `src/front/` — консоль: `ConsoleOutput` печатает доску, `Reader` читает и разбирает ход.

Координаты внутри — пара `Pair(i, j)`: `i` — горизонталь от 0 (первая) до 7, `j` — вертикаль от 0 (A) до 7 (H).
